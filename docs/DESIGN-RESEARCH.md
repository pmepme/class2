# Design Research

## 공개 화면에서 확인한 패턴

- [인프런](https://www.inflearn.com/course/%EC%A7%80%EC%8B%9D%EA%B3%B5%EC%9C%A0%EC%9E%90-%EA%B0%95%EC%9D%98-%EB%A7%8C%EB%93%A4%EA%B8%B0): 강의 중심 탐색과 강의실/플레이어 분리가 익숙하다. 공개 안내에서도 플레이어 안의 수업자료 접근을 확인할 수 있다.
- [인프런 모바일 앱 안내](https://www.inflearn.com/notices/1291029): 보유 강의를 목록에서 확인하고 강의실에서 재생하는 구조가 명확하다.
- [패스트캠퍼스 공개 강의](https://fastcampus.co.kr/dev_online_springboot): 강의의 대상과 학습 결과를 짧은 카피로 설명하고, 긴 커리큘럼을 단계적으로 보여주는 패턴이 강하다.
- [CLASS101+](https://class101.net/ko/pages/hub-page): 카테고리·콘텐츠 큐레이션과 시각적 타일이 탐색을 유도한다.

## 적용한 판단

1. 학생이 처음 들어와도 바로 교육을 둘러볼 수 있도록 목록을 공개하고, 인증은 선택 시점에 요청한다. 신청 맥락을 유지하기 위해 인증 성공 후 선택한 교육으로 돌아간다.
2. 교육 카드는 제목만 나열하지 않고 카테고리·난이도·시간·학습 대상·진행 상태를 묶어 선택 비용을 줄인다.
3. 학술정보관의 신뢰감을 유지하기 위해 다크 남색 기반의 운영 UI와 보라색 진행 색상을 사용하고, 교육 카드 그래픽만 색상 변주를 허용했다.
4. 수강 화면은 플레이어와 자료 다운로드를 한 화면에 두어 학습 중 이탈을 줄인다. 배속·자막은 별도 환경설정으로 숨기지 않고 플레이어 바로 아래에 둔다.

## 차별화 방향

상용 교육 플랫폼의 판매·추천·결제 요소를 가져오지 않고, 캠퍼스 맥락에 필요한 `인증 → 신청 → 수강률 → 완료` 신호만 강조한다. 결과적으로 교육 서비스처럼 익숙하지만, 학생이 해야 할 선택은 더 적다.
