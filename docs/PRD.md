# Library Learn PRD

## 제품 목표

학술정보관 학생이 교육을 찾고, 한양대학교 이메일 OTP로 인증한 뒤, YouTube 기반 영상 교육을 자기 속도에 맞춰 수강하도록 돕는다. 수강률 50% 이상을 수강 완료로 표시하고, 담당자가 교육·수강 현황을 관리할 수 있는 MVP를 제공한다.

## 핵심 사용자

- 학생: 한국인·외국인 대학생. 교육 신청, 영상 수강, 배속·자막 사용, 자료 다운로드, 내 학습 확인.
- 교육 담당자: 학생 명단·교육·자료를 관리하고 신청자 및 수강 데이터를 확인·다운로드.

## MVP 화면

1. 교육 목록: 검색·카테고리 필터·교육별 상태.
2. 이메일 인증: 정확한 `@hanyang.ac.kr` 이메일로 8자리 OTP 발송·검증, 인증 후 Supabase HttpOnly 쿠키 세션 생성.
3. 신청 확인: `교육을 수강하시겠습니까?` 모달에서 예/아니오 선택.
4. 수강 화면: YouTube 임베드, 배속·자막 퀵 컨트롤, 강의자료 다운로드 상태, 진행률 저장.
5. 마이페이지: 수강 중/수강 완료 분리, 진행률 표시, 이어보기.
6. 관리자: 개요 KPI, 학생 활성/비활성, 교육 공개/비공개, 수강 현황, CSV 내보내기.
